Universal Data Extractor Privacy Policy

Last updated: September 10, 2026

1. Overview

This Privacy Policy describes how Universal Data Extractor (the “Extension”), a browser extension published by Avenro Labs, handles information when you use it. The Extension extracts tables, lists, and other structured page data and exports that data locally as CSV, Excel (XLSX), or JSON files. Optional paid Pro features are available through a one-time license.

This policy distinguishes two categories of information:

  • Extracted website content — page data you choose to scan or export, processed locally in your browser and not sent to Avenro Labs or Lemon Squeezy.
  • License / payment data — information used only if you purchase and activate optional Pro features, handled with Lemon Squeezy for payment and license verification.

No account is required to use the Extension. The Extension does not continuously monitor browsing history.

2. Data processed by the extension

Depending on how you use the Extension, it may process:

  • Extracted website content from a page you explicitly scan or export (tables, lists, structured data, and optionally links or image URLs).
  • License-related values you enter or that the Extension generates for Pro activation, validation, or deactivation (such as a license key and installation identifiers).

These categories are handled differently, as described below.

3. Extracted website content

Universal Data Extractor processes website content only after the user explicitly clicks Scan Page or starts an export.

Extracted website content is processed locally in the browser. Extracted tables, lists, links, image URLs, and exported data are not transmitted to Avenro Labs or Lemon Squeezy.

Generated CSV, JSON, and XLSX files are created locally on the user's device. Files you choose to save remain under your control on your device or in locations you select.

Extracted website content is not used for advertising, profiling, determining creditworthiness, or any purpose unrelated to providing extraction and export functionality.

4. Pro licensing and payments

Universal Data Extractor offers optional paid Pro features. The current Pro offer is Universal Data Extractor Pro: a $9.99 one-time lifetime purchase with up to 3 activations.

Payments are processed by Lemon Squeezy outside the extension. Avenro Labs does not process card payments inside the Extension, and Google does not process these payments.

When a user activates, validates, or deactivates a Pro license, the Extension communicates with Lemon Squeezy’s licensing service. License verification may transmit:

  • the license key entered by the user
  • a randomly generated installation identifier
  • a Lemon Squeezy license instance identifier

These values are used only for activation, validation, deactivation, and enforcing the purchased activation limit. License requests do not include extracted webpage content. The Extension does not perform hardware fingerprinting, does not send a hostname for licensing, and does not collect IP addresses for licensing.

License activation state is stored locally in Chrome extension storage.

5. Data transmission

Extracted website content: Processed locally. Not sent to Avenro Labs. Not sent to Lemon Squeezy. Not sent to other third-party servers by the Extension.

License / payment data: If you choose to activate, validate, or deactivate Pro, the Extension sends license verification data (license key and installation/instance identifiers as described above) to Lemon Squeezy. Payment details for purchases are handled by Lemon Squeezy outside the Extension.

6. Local storage

Export files (CSV, JSON, and XLSX) are generated locally on your device and are not uploaded by the Extension.

If you activate Pro, Chrome extension storage may contain:

  • license key
  • license instance ID
  • random install ID
  • license status
  • last successful validation timestamp

The Extension does not store customer name or email for licensing.

7. Third-party services

Lemon Squeezy is the payment and licensing provider for optional Pro purchases. Purchases completed through Lemon Squeezy are also subject to Lemon Squeezy’s own privacy practices and terms.

Avenro Labs does not sell user data. Extracted website content is not shared with third parties. License verification data is sent to Lemon Squeezy only as needed for Pro entitlement checks, as described in this policy.

8. Analytics and advertising

The Extension does not include analytics services, advertising SDKs, or user tracking mechanisms. It does not monitor browsing history.

9. User control

You control when extraction runs by initiating actions such as Scan Page or Export. You can choose which fields to include and how they are ordered before export.

Pro licensing is optional. You choose whether to purchase Pro and whether to activate, validate, or deactivate a license key. You may stop using the Extension or uninstall it at any time through your browser’s extension management settings. Uninstalling removes local extension storage on that installation.

10. Permissions

The Extension uses browser permissions only as needed to provide its features. It does not claim broad browsing access.

  • activeTab — temporary access to the user-selected current tab so the Extension can read page content when you request a scan or export.
  • scripting — executes local extraction code after an explicit user action. The Extension does not use remote code execution.
  • storage — stores local Pro license activation state and related license values described above.
  • optional host permission: https://api.lemonsqueezy.com/* — requested only when license verification is needed so the Extension can communicate with Lemon Squeezy’s licensing service.

11. Security

Extracted website content is processed locally and is not transmitted by the Extension to Avenro Labs or Lemon Squeezy, which limits exposure related to network transmission of that content. License verification requests to Lemon Squeezy use the provider’s licensing endpoints and include only the license-related values described in this policy.

You remain responsible for how you store, share, or further process any files you export and for safeguarding any license key issued to you.

12. Limited Use

Data accessed by the Extension is used only to provide the user-facing extraction and export functionality and, for license data, Pro entitlement verification.

Extracted website content is not used for advertising, profiling, creditworthiness determinations, or unrelated purposes. Avenro Labs does not sell user data.

13. Changes to this policy

Avenro Labs may update this Privacy Policy from time to time. When changes are made, the “Last updated” date at the top of this page will be revised. Continued use of the Extension after an update means you acknowledge the revised policy.
